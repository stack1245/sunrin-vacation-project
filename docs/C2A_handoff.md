-   연구 자료실 Room 진입 및 상호작용

-   비즈네르 암호 입력·검증
-   입력 정규화: 대문자 통일 및 공백 제거
-   비즈네르 성공 후 과학 실험실 장치 단서 표시
-   같은 완료 흐름에서 `%$#@!` 최종 순서 단서 표시
-   `archiveClueFound` 완료 상태와 연결되는 구조
-   암호 퍼즐 및 Room 단위 테스트 작성
-   `dev/archive-test`를 이용한 Phaser 기반 독립 브라우저 테스트 경로
    구성

C 파트의 공식 책임 범위는 연구 자료실 탐색, 두 암호, D/F용 단서, 완료
상태 저장 및 재입장 시 단서 재확인까지다. 과학 실험실 장치 자체와 문서
보관실 기호 퍼즐 자체는 C의 범위가 아니다. fileciteturn2file2

### 5.1 과학 실험실 단서

  -----------------------------------------------------------------------
  구분                                내용
  ----------------------------------- -----------------------------------
  제공 파트                           C

  소비 파트                           D

                                      흐름 완료

                                      가열 순서를 이해할 수 있는 단서

  저장 완료 상태                      `archiveClueFound=true`

  -----------------------------------------------------------------------

C 명세서에서 D에 제공해야 하는 단서는 **화학 기호, 밀도, 산소, 점화,
가열 순서를 이해할 수 있는 정보**로 정의되어 있다. 따라서 D는 이 순서를
과학 실험실의 실제 장치 선택/검증 순서에 연결하면 된다.

  구분             내용
  ---------------- ------------------------------------------
  제공 파트        C
  소비 파트        F

## 8. QA 시나리오

### 8.1 준비 상태

-   시작 위치: 연구 자료실 `archive`
-   필요한 선행 플래그:
    -   `entranceUnlocked=true`
    -   `currentRoom=archive`
-   독립 테스트 페이지에서는 C 파트를 단독 실행하기 위해
    `hasKeycard=true`, `entranceUnlocked=true`, `currentRoom=archive`인
    mock 상태를 사용한다. fileciteturn7file14

### 8.2 정상 동선

1.  연구 자료실에 진입한다.
2.  카이사르 암호를 입력한다.
3.  카이사르 성공 전에는 비즈네르 입력이 활성화되지 않는지 확인한다.
4.  카이사르 성공 후 비즈네르 암호 입력이 활성화된다.
5.  비즈네르 암호를 입력한다.
6.  비즈네르 성공 후 과학 실험실 장치 단서가 표시되는지 확인한다.
7.  D 담당자는 단서가 화학 기호·밀도·산소·점화·가열의 순차 규칙을
    전달하는지 확인한다.
8.  같은 완료 흐름에서 `%$#@!` 단서가 생성되는지 확인한다.
9.  C 완료 상태가 `archiveClueFound=true`로 연결되는지 확인한다.
10. 완료 상태로 재입장했을 때 암호를 다시 풀지 않고 단서를 재확인할 수
    있는지 확인한다.

### 8.3 실패·경계 동선

1.  카이사르 오답 입력 → 실패 메시지만 표시하고 정답은 노출하지 않는다.
2.  카이사르 미완료 상태에서 비즈네르 입력 → 접근 불가.
3.  비즈네르 오답 입력 → 실패 메시지만 표시하고 정답은 노출하지 않는다.
4.  대소문자 차이와 공백이 있는 입력 → 정규화 규칙에 따라 처리한다.
5.  빠른 연속 입력/중복 상호작용 → 완료 이벤트가 중복 발생하지 않는지
    확인한다.
6.  미완료 상태 재접속 → 승인되지 않은 중간 저장 필드 없이 자료실 퍼즐
    시작 상태로 돌아가는지 확인한다.
7.  완료 상태 재입장 → 두 후속 단서를 다시 확인할 수 있는지 확인한다.

C 명세서의 필수 테스트 항목도 카이사르 전 비즈네르 잠금, 정답 정규화,
비즈네르 전 단서 미노출, 완료 저장, 재입장, 미완료 초기화를 포함한다.
